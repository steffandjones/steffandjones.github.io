## How to Deploy to GitHub Pages

1. **Download all files** from this chat

2. **Go to your GitHub repository**
   - Navigate to https://github.com/steffandjones/steffandjones.github.io

3. **Upload files**
   - Click "Add file" → "Upload files"
   - Drag ALL the HTML files + headerimage.png
   - Make sure they're in the ROOT directory (not in a folder)

4. **Commit changes**
   - Add commit message: "Update portfolio with multi-page design"
   - Click "Commit changes"

5. **Wait 2-3 minutes**
   - GitHub Pages will automatically rebuild
   - Visit https://steffandjones.github.io

## Customization

### To change project images:
Replace the image URL in each project page's hero section:
```html
<div class="hero" style="background-image: url('YOUR-IMAGE-URL');">
```

### To add new projects:
1. Duplicate any existing project HTML file
2. Update the content (title, subtitle, overview, etc.)
3. Add a new card to index.html linking to your new page

### To update contact info:
Edit the social links in index.html (LinkedIn, Instagram, Email)
