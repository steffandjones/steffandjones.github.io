3D Holographic Display

ES50: Electrical Engineering · Final Project

Project Overview

Designed and programmed a 3D holographic fan display system using Arduino microcontrollers. The project creates the illusion of three-dimensional images floating in mid-air through persistence of vision, achieved by precisely controlling LED strips rotating at high speed.

Key Achievements

  • Designed and built custom PCB for LED control circuitry
  • Programmed Arduino to synchronize LED patterns with rotation
  • Created custom visualization software for content creation
  • Achieved stable 3D holographic projections
  • Integrated wireless control via Bluetooth

Technical Details

Electrical Engineering: ES50 (Introduction to Electrical Engineering) culminates in a final project built from scratch using the electronics fundamentals covered in the course. The holographic fan works on persistence of vision: a 1D strip of LEDs is mounted on a rotating arm, and by precisely timing which LEDs fire at each angular position as the arm spins, the eye integrates the individual flashes into a coherent 2D image that appears to float in mid-air. Rather than using position sensors, the motor was run at a fixed, calibrated speed and the LED timing was set to match that speed — making the image timing stable and predictable as long as the motor held its target RPM.

Software: The core of the software is a coordinate mapping algorithm: a 2D pixel image is converted into a lookup table specifying, for each angular step of the arm's rotation, which LEDs on the 1D strip should be active. With the motor running at a known fixed speed, the Arduino fires each LED subset at the corresponding time interval with microsecond-level precision, stepping through the full lookup table once per revolution to produce the image. A Bluetooth serial connection allows new images to be loaded wirelessly without stopping the device.

CAD & Fabrication: The housing presented a real mechanical design challenge: all electronics had to rotate with the arm, so the breadboard, battery, and Arduino needed to be packaged compactly and balanced about the rotation axis. The enclosure was designed in CAD and 3D printed, with integrated channels to route the LED strip cable along the inside of the arm so nothing protrudes or tangles during rotation. The assembly mounts directly to the motor shaft, with geometry sized to fit the specific fan motor used. Several printed iterations were needed to get the fit, balance, and cable routing right.
