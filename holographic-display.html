3D Holographic Display

Arduino-Based Holographic Fan Project

Project Overview

Designed and programmed a 3D holographic fan display system using Arduino microcontrollers. The project creates the illusion of three-dimensional images floating in mid-air through persistence of vision, achieved by precisely controlling LED strips rotating at high speed.

Key Achievements

  • Designed and built custom PCB for LED control circuitry
  • Programmed Arduino to synchronize LED patterns with rotation
  • Created custom visualization software for content creation
  • Achieved stable 3D holographic projections
  • Integrated wireless control via Bluetooth

Technical Details

The system uses Hall effect sensors to detect the angular position of the rotating arm, allowing precise timing of LED activations to create coherent 3D images. Custom firmware handles high-speed data transfer to RGB LED strips while maintaining refresh rates necessary for smooth visual persistence.
